# Portfolio — Séphora Nowicki

Site statique en HTML, CSS et JavaScript, prêt pour GitHub Pages.

## Fichiers
- `index.html` : contenu et structure du site
- `style.css` : mise en page, couleurs, typographies et adaptation mobile
- `script.js` : menu mobile et année automatique

## Publier avec GitHub Pages
1. Crée un dépôt GitHub, par exemple `portfolio-sephora`.
2. Décompresse ce projet et importe les fichiers à la racine du dépôt.
3. Ouvre **Settings → Pages**.
4. Dans **Build and deployment**, choisis **Deploy from a branch**.
5. Sélectionne `main` et `/ (root)`, puis **Save**.

## À propos des photographies
Les balises d'images utilisent actuellement les URL publiques du portfolio de référence `sephoranowicki.vercel.app` afin de conserver les visuels pendant la première intégration. Elles restent donc dépendantes de la disponibilité du site source. Pour héberger les photos dans ton propre dépôt, ajoute les images autorisées dans un dossier `assets/` et remplace les URL distantes dans `index.html` par leurs chemins locaux.

## À personnaliser avant publication
Vérifie les coordonnées de contact, les liens externes et les textes professionnels. Les informations conservées sont celles indiquées dans la demande et le contenu du site de référence ; relis-les pour confirmer qu'elles sont toujours exactes.
